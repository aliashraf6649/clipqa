# ClipQA

Ask questions about a short street or traffic clip and get answers with timestamps and the frames that prove them. Work in progress.

## Data

Evaluation clips come from the [MOT17 benchmark](https://motchallenge.net/data/MOT17/) (MOTChallenge), licensed under [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/). The data is not included in this repo; download it from the link above.

Milan, Leal-Taixé, Reid, Roth, Schindler. *MOT16: A Benchmark for Multi-Object Tracking.* arXiv:1603.00831, 2016.
